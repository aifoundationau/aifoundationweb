ChatConfidentiality

3. Multi-Tenant Tag Partitioning & Chat Confidentiality

Our platform includes a unified SuperAdmin Message Box with rigid architectural privacy protections:

  • Confidentiality of Tenant Discriminators: Each message ingested carries an internal tenant identifier tag. This tag is confidential and readable strictly by SuperAdmins. Standard supporters and non-superadmin users never receive tenant classification keys.
  • Conversation Thread Isolation: Supporter chat threads are strictly partitioned to the sender’s Firebase UID (conv_${uid}). Regular supporters can read and write exclusively within their own thread.
  • Prohibition of File Uploads: To prevent unauthorized data transfer, script injection, and inadvertent leakage of sensitive personal files, the chat interface is strictly limited to text and verified URLs (hasUploads: false). Binary file uploads are rejected at the server level.
PCI_DSS_SAQ_A

4. Payment Card Processing & PCI DSS Scope Minimization

Financial transactions, donations, and token purchases are processed with the highest assurance security protocols:

  • Zero Cardholder Storage (PCI DSS SAQ A): The AI Foundation complies with the Payment Card Industry Data Security Standard (PCI DSS v4.0) under Self-Assessment Questionnaire A (SAQ A). We never receive, process, store, or transmit raw credit card numbers (PAN, CVV/CVC, or expiration dates) on our servers.
  • Client-Side Tokenization: All payment fields are rendered in encrypted iframes hosted directly by Stripe (js.stripe.com) or PayPal. Our servers only handle tokenized references (pi_*, cs_*) and integer quantities.
SevenYearRetention

5. Uniform 7-Year Statutory Data Retention & Disposal

In compliance with statutory recordkeeping under the Corporations Act 2001 (Cth) Section 286, the Australian Taxation Office (ATO), and Australian Privacy Principle 11.2:

  • Mandatory Retention Window: All financial transactions, donation records, receipts, supporter chat interactions, and identity verification logs are retained for exactly 7 years (2,557 days) from generation.
  • Immutable Audit Trails: During the 7-year lifecycle, records are preserved against modification or unauthorized erasure.
  • Secure Disposal Routine: At the expiration of the 7-year statutory lifecycle, non-financial identifying personal records (PII) are permanently de-identified or irreversibly purged using cryptographically verified destruction routines.
SSRFProtection

6. Media Storage, Open Graph Scraping & SSRF Safeguards

1. Ephemeral Media Processing: Media uploads approved for public project entries or articles are processed through CDN endpoints (ImgBB Cloud CDN). Image base64 buffers are held in ephemeral transit memory and purged immediately post-transmission.

2. SSRF Protection: When scraping web links for Open Graph previews, our server actively checks and rejects connections to private subnets (RFC 1918), loopback addresses (127.0.0.0/8), link-local allocations (169.254.0.0/16), and internal cloud metadata services.

3. XSS Sanitization: All user-generated text rendered on screen is converted to safe HTML entities (&amp;, &lt;, &gt;) to protect users against Cross-Site Scripting (XSS).

DataEncryption

7. Cookies, Local Storage & Security Safeguards

We use minimal functional cookies and local storage tokens strictly required for site operation:

  • adminAuth: Session verification cookie for authenticated administrators.
  • aifoundation_locale: Local storage cache preserving user-selected regional preferences (date/time formats and suburb/state).

Encryption in Transit & At Rest: All web traffic is encrypted with TLS 1.3 / HTTPS with HSTS enabled. All Cloud Firestore database records are encrypted with AES-256 at rest.
